## 🚀 PARA PUBLICAR EN GITHUB

1. Crea repositorio en github.com
2. Sube todos los archivos HTML y MD
3. Ve a Settings > Pages
4. Selecciona rama "main"
5. ¡Listo! Tu sitio estará en: `https://usuario.github.io/repositorio`

### Opción 2: Usando Terminal (Git)
```bash
git clone https://github.com/usuario/repositorio.git
cd repositorio
# Coloca los archivos HTML y MD aquí
git add .
git commit -m "Agregar sitio de bibliografía"
git push
```

## ✨ DETALLES TÉCNICOS

### Colores de Diseño
```css
Fondo principal:    linear-gradient(135deg, #0a0a0a, #1a1a1a)
Verde neon:         #00ff88 (bordes y textos principales)
Rosa neon:          #ff006e (acentos y bordes secundarios)
Amarillo:           #ffff00 (títulos y acentos)
Negro opaco:        rgba(0, 0, 0, 0.85-0.95) (fondos de contenido)
```

### Efectos CSS
```css
Transición principal:   cubic-bezier(0.34, 1.56, 0.64, 1)
Box shadow neon:        0 8px 25px rgba(0, 255, 136, 0.2)
Hover lift:            translateY(-8px) scale(1.05)
Filter hover:          brightness(1) contrast(1.3)
```

### Responsividad
```css
Breakpoint móvil:      max-width: 480px
Font sizes:            clamp() para escalado automático
Grid layout:           CSS Grid 2 columnas (adaptativa)
Aspect ratio:          Mantiene proporciones
```
